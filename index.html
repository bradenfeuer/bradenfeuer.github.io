Donkey Kong Handheld

Jan – Apr 2026
MSPM0G3507bare-metal Ccustom PCBST7735 TFTADC / DACinterrupt-driven FSMs

A fully playable Donkey Kong clone running bare-metal at 80 MHz — ECE 319K final project, with Pranav Shivashankar.

Features

  • Up to 10 barrels on randomized pre-computed paths
  • Table-driven jump physics — tunable without code changes
  • DAC sound effects; bilingual UI via slide potentiometer
  • Custom PCB: MCU, TFT, buttons, ADC pot, DAC audio

Engineering Challenges

  • Two timer ISRs drive game logic; SPI stays out of interrupt context
  • Dirty-rect rendering to keep frame rate up over slow SPI
  • Fitting sprites, paths, and audio in a small memory budget
  • Breadboard prototype → custom PCB bring-up
