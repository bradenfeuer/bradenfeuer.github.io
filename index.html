Smart LED Matrix Display

Jun – Aug 2026
ESP32-S3 · C++ · FreeRTOS · 2× HUB75 64×32 · KiCad PCB · Spotify / Open-Meteo / Todoist / Finnhub

A Wi-Fi desk dashboard on a 128×32 RGB matrix: Spotify now-playing with a live progress bar and scrolling track info, weather, Todoist tasks, stock quotes, and a clock — falling back to a custom animated aurora with a twinkling starfield when idle. One FreeRTOS task per API on core 0; the render loop on core 1 never blocks on network I/O. A self-healing watchdog stack recovers from Wi-Fi drops, stale TLS connections, and worse.

The real education was the hardware: a sagging power supply, a burned-out barrel connector, and signal-integrity gremlins on jumper wires — which led me to design my first custom PCB.

Donkey Kong Handheld

Jan – Apr 2026
MSPM0G3507 · bare-metal C · custom PCB · ST7735 TFT · ADC / DAC · interrupt-driven FSMs

A fully playable Donkey Kong clone running bare-metal at 80 MHz on a custom PCB: up to 10 barrels on randomized pre-computed paths, table-driven jump physics, DAC sound effects, and a bilingual UI selected by slide potentiometer. Two hardware timer ISRs drive the game engine while all SPI display traffic stays out of interrupt context — dirty-rect rendering keeps the frame rate up over a slow SPI display. ECE 319K final project, with Pranav Shivashankar.
