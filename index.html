Donkey Kong Handheld

Jan – Apr 2026
MSPM0+Ccustom PCBST7735 TFTADC / DACinterrupt-driven FSMs

A fully playable Donkey Kong clone running bare-metal at 80 MHz MSPM0+. Built as the final project for ECE 319K.

Features

  • Up to 10 barrels following randomized precomputed paths
  • Table-driven jump physics for easy gameplay tuning
  • DAC sound effects and bilingual UI selected via slide potentiometer
  • Custom PCB integrating MCU, TFT display, buttons, ADC input, and DAC audio

Engineering Challenges

  • Three interrupt timers (SysTick, TIMG12, TIMG0) drive game logic while keeping SPI communication out of interrupt context
  • Dirty-rectangle rendering maintains smooth frame rates over a bandwidth-limited SPI display
  • Designed collision detection and animation systems that remained responsive within tight CPU and memory constraints
  • Transitioned from a breadboard prototype to a fully assembled custom PCB
